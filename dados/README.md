## 🇬🇧 About
Repository dedicated to tracking my practical journey in bioinformatics, utilizing Linux, Python, R, and Git. This project covers everything from raw data processing and data analysis to variant calling and workflow automation.

### 🛠 Tech Stack & Environment
* **OS & Tools:** Linux (Bash), VS Code, Git & GitHub, WSL
* **Languages:** Python, R, Nextflow
* **Genomic Tools:** GATK (HaplotypeCaller), BWA, Samtools, Docker
* **Data Analysis:** Pandas, Biopython, Data Visualization

### 📂 Repository Structure
* `/workflows`: Nextflow scripts for automated pipeline execution.
* `/scripts_analise`: Python and R scripts for data cleaning, statistical analysis, and visualization.
* `/dados`: Sample input data (FASTA/FASTQ).
* `/results`: Generated VCFs, filtered tables, and reports.

## 🇧🇷 Sobre
Repositório criado para registrar minha jornada prática em análise de dados em bioinformática, utilizando Linux, Python, R e Git. Este projeto abrange desde o processamento de dados brutos e análise de dados até a chamada de variantes e automação de fluxos.

### 🛠 Tecnologias e Ambiente
* **Sistema e Ferramentas:** Linux (Bash), VS Code, Git & GitHub, WSL
* **Linguagens:** Python, R, Nextflow
* **Ferramentas Genômicas:** GATK (HaplotypeCaller), BWA, Samtools, Docker
* **Análise de Dados:** Pandas, Biopython, Visualização de Dados

### 📂 Estrutura do Repositório
* `/workflows`: Scripts em Nextflow para execução automatizada de pipelines.
* `/scripts_analise`: Scripts em Python e R para limpeza de dados, análise estatística e visualização.
* `/dados`: Dados de entrada (FASTA/FASTQ).
* `/results`: VCFs gerados, tabelas filtradas e relatórios.
